# Guilherme Pereira — Portfolio

Personal portfolio of Guilherme de Almeida Pereira, based in Brisbane, Australia. It presents professional experience and practical projects for IT Support, Service Desk / Desktop Support and Junior Software Development opportunities.

[Visit the portfolio](https://guilhermedealmeidapereira.github.io/)

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub Pages

## Main sections

- Hero and professional profile
- About, experience and education
- Selected projects, featuring Intelligent Fraud Detection
- Technical skills, with a separate Currently Learning area
- Contact and footer navigation

New projects will be added as they are completed.

## Local preview and deployment

Open `index.html` with VS Code Live Server. The site has no build step or package dependencies.

GitHub Pages serves the static files from this repository. Keep `index.html`, `robots.txt` and `sitemap.xml` at the publishing root, alongside `assets/`. Publication is managed through the repository's Pages settings.

Before publishing, check navigation, keyboard focus, reduced motion and responsive layouts in Live Server. Contact links use email, LinkedIn and GitHub; no contact backend is required.
